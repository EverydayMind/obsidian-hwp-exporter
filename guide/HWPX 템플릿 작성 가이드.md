# HWPX 템플릿 작성 가이드

HWP Exporter는 노트를 한글 문서(.hwpx)로 내보낼 때 **템플릿**의 모양을 따릅니다. 템플릿은 한글에서 열고 고치는 평범한 .hwpx 파일입니다. 이 가이드는 템플릿을 고치거나 새로 만드는 방법을 설명합니다.

> [!tip] 가장 쉬운 시작
> 같은 폴더의 `견본 템플릿.hwpx`를 복사해 한글에서 엽니다. 쓸 수 있는 표시가 설명과 함께 모두 들어 있습니다. 각 표시의 글자 모양·문단 모양만 원하는 대로 바꾸고 다른 이름으로 저장하면 새 템플릿이 됩니다. 설명 글은 결과물에 나오지 않습니다.

## 1. 동작 방식

- 템플릿 안에는 `{{H1}}`, `{{BODY}}`, `{{QUOTE}}` 같은 **표시(marker)**가 들어 있습니다.
- 플러그인은 표시가 있는 자리의 **글자 모양**(글꼴·크기·색), **문단 모양**(정렬·간격·들여쓰기·테두리·배경), **스타일**을 읽어 노트의 같은 요소에 적용합니다.
- 예를 들어 `{{H1}}` 글자를 20pt 남색으로 바꾸면, 내보내는 모든 문서의 제목 1(`# 제목`)이 20pt 남색이 됩니다.
- 모든 표시는 선택입니다. 없는 요소는 기본 모양으로 그립니다.

## 2. 규칙 표 만들기

- 표 셀 표시(`{{CELL_…}}`)를 뺀 모든 표시는 **1×1 표(칸 하나짜리 표)** 안에 씁니다. 이 표를 "규칙 표"라고 부릅니다.
- 결과물에서는 규칙 표의 테두리가 지워지고 칸 안의 내용만 나옵니다. 표시 글자만 노트 내용으로 바뀝니다.
- 표시 앞뒤에 쓴 글자와 위아래 빈 문단도 그대로 나옵니다. 예를 들어 `□ {{H2}}`라고 쓰면 모든 제목 2 앞에 `□ `가 붙습니다.
- 규칙 표 안에 다시 넣은 표는 실제 내용으로 나옵니다(제목 띠 같은 장식에 씁니다).
- 규칙 표 위의 설명 문단은 결과물에서 빠집니다.

## 3. 표시 목록

| 분류 | 표시 | 노트에서 |
|---|---|---|
| 제목 | `{{H1}}` … `{{H9}}` | `#` … `#########` |
| 본문 | `{{BODY}}` | 일반 문단 |
| 링크 | `{{LINK}}` | `[글](주소)`, `[[노트]]` |
| 코드 | `{{CODE}}`, `{{CODE_INLINE}}`, `{{CODE_LANG}}` | 코드 블록, `` `코드` ``, 코드 언어 표시 |
| 인용·콜아웃 | `{{QUOTE}}`, `{{QUOTE_INFO}}`, `{{QUOTE_WARN}}`, `{{QUOTE_SUCCESS}}`, `{{QUOTE_DANGER}}`, `{{CALLOUT_<종류>}}`, `{{CALLOUT_TITLE}}`, `{{CALLOUT_TITLE_<종류>}}` | `> 인용`, `> [!note] 제목` |
| 수평선 | `{{HR}}` | `---` |
| 글자 서식 | `{{STRONG}}`, `{{EMPH}}`, `{{STRIKE}}`, `{{UNDERLINE}}`, `{{HIGHLIGHT}}` | `**굵게**`, `*기울임*`, `~~취소선~~`, `<u>밑줄</u>`, `==강조==` |
| 수식 | `{{MATH}}`, `{{MATH_INLINE}}` | `$$ … $$`, `$…$` |
| 각주 | `{{FOOTNOTE}}` | `[^1]` |
| 그림·캡션 | `{{FIGURE}}`, `{{CAPTION}}`, `{{TABLE_CAPTION}}` | 그림만 든 문단, 그림 캡션, 표 캡션 |
| 할 일 | `{{TASK_OPEN}}`, `{{TASK_DONE}}` | `- [ ]`, `- [x]` |
| 목록 | `{{LIST_BULLET_1}}` … `{{LIST_BULLET_7}}`, `{{LIST_ORDERED_1}}` … `{{LIST_ORDERED_7}}` | `-` 목록, `1.` 목록(숫자는 들여쓰기 단계) |
| 표 | `{{TABLE}}`, `{{CELL_…}}` | Markdown 표 |
| 고정 영역 | `{{CONTENT}}`, `{{META:키}}` | 본문 자리, YAML 값 |

> [!note] `{{title}}`은 템플릿 표시가 아닙니다
> 노트 본문에 쓴 `{{title}}`은 내보낼 때 노트 파일 이름으로 바뀝니다. 템플릿에서 문서 제목을 넣으려면 `{{META:title}}`을 씁니다.

## 4. 요소별 규칙

### 인용과 콜아웃

- 인용문은 `{{QUOTE}}`의 모양을 씁니다. 상자 배경과 왼쪽 강조선은 그 문단의 **문단 테두리/배경**으로 줍니다.
- 인용문 첫 글자가 이모지면 종류별 상자를 씁니다.
  - `{{QUOTE_INFO}}`: 💡 ℹ️ 📌 ✍️ 🔎 📝
  - `{{QUOTE_WARN}}`: ⚠️ ❗ 🚨
  - `{{QUOTE_SUCCESS}}`: ✅ ✔️
  - `{{QUOTE_DANGER}}`: ❌ 🚫 ⛔
- Obsidian 콜아웃 `> [!종류] 제목`은 `{{CALLOUT_<종류>}}` → 종류에 맞는 `{{QUOTE_*}}` → `{{QUOTE}}` 순으로 모양을 고릅니다. note·tip 등은 INFO, success는 SUCCESS, warning·question은 WARN, danger·bug는 DANGER입니다. 종류 이름은 한글도 됩니다(`{{CALLOUT_회의}}`).
- 콜아웃 제목 줄은 `{{CALLOUT_TITLE_<종류>}}` → `{{CALLOUT_TITLE}}` 순으로 고릅니다. 제목 줄을 상자 안에 넣으려면 같은 종류 상자와 똑같은 문단 테두리·배경을 줍니다.
- 규칙 문단에서 표시 앞에 쓴 글자(`※` + 탭 + `{{QUOTE}}`)는 모든 인용문 앞에 붙습니다.

### 수평선

`{{HR}}` 문단의 **아래쪽 문단 테두리**가 선이 됩니다. 결과물에는 빈 문단 하나로 나옵니다.

### 코드

- 코드 블록 상자는 `{{CODE}}` 문단의 테두리·배경으로 만듭니다. 문단 테두리의 "문단 테두리 연결"을 켜면 여러 줄이 한 상자가 됩니다.
- 상자 안쪽 여백은 문단 테두리의 간격으로 조절합니다.

### 글자 서식

- `{{STRONG}}`, `{{EMPH}}`, `{{STRIKE}}`, `{{UNDERLINE}}`은 본문(`{{BODY}}`)과 **다른 부분만** 적용합니다(글자색, 취소선·밑줄 모양과 색).
- `{{LINK}}`, `{{CODE_INLINE}}`, `{{HIGHLIGHT}}`, `{{MATH_INLINE}}`은 여기에 음영, 글꼴, 굵게·기울임도 적용합니다.
- 글자 **크기는 바꾸지 않습니다.** 그래서 제목 안의 링크는 제목 크기를 유지합니다.

### 목록

- `{{LIST_ORDERED_1}}` 규칙에는 `1.`처럼 첫 번호만 써 두면 번호가 자동으로 올라갑니다. `가.`, `①`, `I.`, `(a)` 같은 형식도 됩니다.
- 항목 사이 간격은 목록 문단의 "문단 아래 간격"으로 줍니다.
- 문단 모양에 한글 번호 매기기를 설정하면 번호는 한글이 매깁니다.

### 각주

본문의 `[^1]`과 `[^1]: 내용`은 한글 각주가 됩니다. 번호 모양은 템플릿의 각주 모양 설정을, 각주 문단 모양은 `{{FOOTNOTE}}` → 템플릿의 "각주" 스타일 → 본문 순으로 따릅니다.

### 표

- 표 칸 모양은 **실제 표** 안에 칸마다 표시를 써서 정합니다. 결과 표의 행·열 수는 노트의 표를 따릅니다.
- 행 위치: `HEADER`(머리 행), `TOP`, `MIDDLE`, `BOTTOM`. 열 위치: `LEFT`(첫 열), `CENTER`(가운데 열), `RIGHT`(마지막 열). 예: `{{CELL_HEADER_LEFT}}`, `{{CELL_MIDDLE_CENTER}}`. LEFT/CENTER/RIGHT는 정렬이 아니라 열 위치입니다.
- 추가 규칙: `{{CELL_NUMBER}}`(숫자만 든 칸), `{{CELL_STUB}}`(본문 첫 열), `{{CELL_ODD}}`/`{{CELL_EVEN}}`(줄무늬 행), `{{CELL_BODY}}`(나머지 본문 칸).
- 노트의 정렬(`:---`, `:---:`, `---:`)은 칸 정렬에 반영됩니다. 열 너비는 노트 표 구분선(`---`)의 길이 비율을 따릅니다.

## 5. 표시 옵션

표시 뒤에 `|`로 옵션을 붙입니다.

| 예 | 뜻 |
|---|---|
| `{{H1\|pageBreak}}`, `{{H1\|pageBreak=no}}` | 그 수준 제목 앞에서 쪽을 나눔/나누지 않음 |
| `{{H3\|num=%1.%2.%3.}}` | 제목 앞에 `1.2.3.` 같은 계층 번호를 붙임 |
| `{{H3\|list=2}}` | 이 제목 아래 목록을 2단계 목록 모양부터 시작 |
| `{{TABLE\|width=100%}}` | 표 폭. `template`, `avail`(본문 폭), `80%` 등 |
| `{{TABLE\|columns=equal}}` | 열 너비를 모두 같게(기본은 내용 길이에 맞춤) |
| `{{QUOTE_<이름>\|callouts=warning,caution}}` | 이 상자를 쓸 콜아웃 종류 |
| `{{QUOTE_<이름>\|emoji=⚠️,❗}}` | 이 상자를 쓸 첫 글자 이모지 |
| `{{QUOTE:요약\|lead}}` | 제목 바로 아래 첫 인용문을 요약 상자로 |

기본 네 종류 밖의 `{{QUOTE_<이름>}}`은 `callouts=`나 `emoji=`가 있어야 쓰입니다.

## 6. 같은 요소의 다른 모양 (변형)

- 표시 뒤에 `:이름`을 붙여 다른 모양을 하나 더 정의합니다: `{{BODY:요약}}`, `{{H2:부록}}`, `{{QUOTE:주의}}`, `{{CODE:작게}}`, `{{CELL_HEADER_LEFT:compact}}`.
- 노트에서 고르는 방법:
  - 블록 바로 앞에 `<!-- hwpx:style=요약 -->`
  - 콜아웃 `> [!요약] 제목` (`{{CALLOUT_요약}}`이 없고 `{{BODY:요약}}`이 있을 때)
  - YAML `hwpx-table: compact` → 문서의 모든 표가 `{{CELL_*:compact}}` 모양
- 고른 변형이 템플릿에 없으면 기본 모양을 씁니다.

## 7. 번호

### 번호 자리

규칙 문단에 `{{#}}`을 쓰면 그 자리만 번호로 바뀝니다. 예: `제{{#}}장`. 형식을 정하려면 `{{#:가}}`, `{{#:①}}`, `{{#:㉠}}`, `{{#:I}}`, `{{#:i}}`, `{{#:A}}`, `{{#:a}}`를 씁니다. 그림·표 캡션 규칙에서도 씁니다.

### 숫자로 시작하는 제목

| 표시 | 노트 | 결과 |
|---|---|---|
| `{{H2:1.}}` | `## 17. 개요` | `17. 개요` (번호 유지) |
| `{{H3:1)}}` | `### 23) 상세` | `23) 상세` |
| `{{H2:1.1}}` | `## 2.10 상세` | `2.10 상세` |
| `□ {{H2:1.\|strip}}` | `## 17. 개요` | `□ 개요` (번호 지움) |

번호 없는 제목은 일반 `{{H2}}` 모양을 씁니다.

### 기호로 시작하는 문단

`{{□}}`, `{{ㅇ}}`, `{{1.}}`처럼 쓰면 그 기호로 시작하는 노트 문단에 이 모양을 적용합니다. 기호 앞 공백 수까지 맞아야 하며(`{{  □}}`), 공백 수와 상관없이 맞추려면 `{{~□}}`처럼 씁니다. 기호는 결과에서 지워지고 규칙의 모양이 대신합니다(숫자는 남습니다).

## 8. 표지·결재란과 문서 정보

- 본문이 들어갈 자리에 `{{CONTENT}}`만 적은 문단을 두면, 그 앞뒤의 일반 문단(표지, 결재란, 안내 문구)은 결과물에 그대로 남습니다.
- `{{META:title}}`, `{{META:author}}`처럼 쓰면 노트 맨 위 YAML 값으로 바뀝니다. 머리말·꼬리말 안에서도 바뀝니다.
- 날짜는 `{{META:date|format=YYYY. M. D.}}`처럼 형식을 줄 수 있습니다(`YYYY`, `YY`, `MM`, `M`, `DD`, `D`).
- `title`이 없으면 노트 파일 이름을 씁니다.

```yaml
---
title: 2026년 상반기 사업 보고
author: 기획팀
date: 2026-10-24
---
```

## 9. 검사와 문제 해결

- 템플릿을 고친 뒤 명령 팔레트(`Ctrl+P`)에서 **Inspect HWPX template**을 실행합니다(설정의 **템플릿 검사** 버튼도 같습니다). 인식한 표시, 오타로 보이는 표시와 고칠 이름(예: `{{QUOTE_WARNING}}` → `{{QUOTE_WARN}}?`), 없어서 기본 모양으로 그릴 요소를 보여 줍니다.
- 내보내기 목록에는 설정에서 고른 **템플릿 폴더 바로 안**의 .hwpx만 나옵니다. 하위 폴더 속 파일은 보이지 않습니다.
- 박스·선·색·간격은 결과물을 한글에서 열어 확인합니다.
- 동봉 템플릿을 고쳐 쓸 때는 다른 이름으로 저장하세요. **Install bundled templates**를 다시 실행해도 같은 이름의 파일은 덮어쓰지 않습니다.
